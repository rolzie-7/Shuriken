# Shuriken

A free AI coding agent for your terminal. One sponsored line under the status bar pays for the model, so there is no subscription and no API key.

**Status: in development. Nothing can be installed yet.**

- Website: https://rolzie-7.github.io/Shuriken/
- To hear about the first release: click **Watch** at the top of this page, choose **Custom**, and tick **Releases**.

This repository currently holds the website only. Shuriken is built on [OpenCode](https://opencode.ai) and is not affiliated with it.
