Attention is all you need... To run your agents for free!

Shuriken is a coding agent for your terminal, built on OpenCode. It runs open-weight models, and you never enter an API key or a card. While it works, one sponsored line sits under the status bar. Your attention on that line is what pays for the model.

Who pays

Running a model costs money on every request. Most coding agents pass that cost to you as a subscription or an API bill. Shuriken passes it to an advertiser.

  1. You give the agent a task

    It reads, edits and runs code in your project, the way OpenCode does.

  2. One sponsored line appears

    It sits under the status bar and is matched to the topic you are working on, such as databases or testing.

  3. The advertiser's payment covers the model

    Advertisers pay each time their line is shown. We use open-weight models and prompt caching to keep the cost low enough for that one line to cover it.

What leaves your machine

An agent has to send your prompt somewhere to get an answer, and an ad needs something to be matched against. This is the full list of who receives what.

Where it goes What it receives What it doesn't
The model provider

Your prompt and the files the agent reads, so the model can do the work.

Anything to keep. We only route to providers that commit by contract to store nothing once they have answered (zero data retention).

Adverts. They are never added to what the model sees, so they can't steer its answers.
The ad network

A short topic for your request, for example "Postgres connection pooling", with secrets and personal data removed on your machine first.

Your IP address and the client's User-Agent. Ad networks require both to detect fraud.

Your code, your files or your repository.

Keys, passwords and tokens. A local filter strips them before any request is made.
Shuriken's servers

Requests pass through our gateway, so that no API key ever sits on your machine.

The gateway is still being built. Before launch we will publish exactly what it logs and for how long.

What the ad line can't do

  • Take more than its line. One line, labelled Sponsored. No pop-ups.
  • Appear in your code. Nothing sponsored is ever written into files the agent creates or edits.
  • Talk to the model. The ad is fetched separately and drawn in the interface only. The model never sees it.
  • Read your repository. Matching uses the topic of your request, not your source.

Questions

Is it really free?

Yes. There is no subscription, no API key and no card. Advertisers pay for the sponsored line, and that pays for the model. There will be a daily usage limit to keep those two in balance.

Which models does it use?

Open-weight coding models, starting with DeepSeek, served by providers that work under zero-data-retention terms.

Can I turn the ad off?

No. The ad line is what pays for the model. If you would rather pay with money, OpenCode itself works with your own API key.

When can I use it?

There is no date yet. Shuriken is in development, and nothing can be installed today. Watching the GitHub repo is the way to hear about the first release.

Is Shuriken part of OpenCode?

No. Shuriken is built on OpenCode, which is open source, and is a separate project run by a different team.

Shuriken isn't released yet.

Watch the repository on GitHub and you will get a notification when the first version ships. That is the whole waitlist.
